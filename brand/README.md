# Naqsha brand files

- `logo-source.png`: the logo, a hexagon of topographic layers in navy, teal and saffron.
- `logo-transparent.png`: background removed by colour key (white to transparent with a soft ramp, colours
  un-premultiplied at the edges). Use on light backgrounds.
- `logo-dark-ui.png`: same, with the navy band lifted slightly so it separates from the dark app ground. Used in the app.
- `cutout.swift`: Apple Vision subject cutout, kept for photographic sources (it drops detached parts of flat logos).
- App sizes live in `frontend/public/` (`logo-512/192/64.png`, `favicon-32.png`).

Palette: navy `#0B2744` (ink, surfaces), teal `#0F8A82` (actions, done), saffron `#F4A62A` (now, brand, progress).
Type: Archivo (variable, width axis) for the interface; Noto Nastaliq Urdu for the wordmark نقشہ.
